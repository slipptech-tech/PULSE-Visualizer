Pulse Visualizer is a real-time audio visualization and music video rendering studio built with Python.

The application transforms music into dynamic, audio-reactive visuals using frequency analysis, beat detection, particles, waves, spectrums, geometric effects, neon rendering and customizable visual layers.

# Features
Real-time audio visualization
Beat, bass, mid and treble detection
Audio-reactive effects and animations
Multiple visualization engines
Spectrum, waveform, particles, vortex, tunnel, radial and geometric visualizers
Customizable colors, glow, particles, grids and post-processing effects
Multiple aspect ratios including 16:9, 21:9, 4:3, 1:1 and 9:16
Custom output resolutions up to 4K
PNG frame export
PNG image sequence export
MP4 video rendering with audio
Adjustable FPS and rendering quality
Project presets and .pulse.json project files
Drag-and-drop audio loading
Real-time preview
Configurable audio sensitivity and smoothing
Audio Reactive System

Pulse Visualizer analyzes different frequency ranges independently, allowing visual elements to respond to specific parts of the music.

# The engine can react to:

Bass and kick
Mid frequencies and melodies
High frequencies and percussion
Overall volume
Beat intensity

This allows different visual elements to move, scale, glow and pulse according to the structure of the audio.

# Rendering

The renderer supports different resolutions, aspect ratios and frame rates, making the application suitable for music visualizers, background videos, visual effects, social media content and experimental audiovisual projects.

FFmpeg is used for video encoding and audio integration during MP4 rendering.

# Project

PulseVisualizerStudio is designed as an extensible open-source project. New visualization engines, effects, audio analysis methods and rendering features can be added without rebuilding the entire application.
